# JavaScript

1. **JS Basics**

   * Arithmetic operations, types
   * `prompt` / `alert`
   * `console.log` / `document.write` output

2. **JS Conditions**

   * `if/else`, ternary operators, `switch`
   * Login/status logic, discounts
   * Day/month case handling

3. **JS Loops**

   * `for`, `while`, `do..while`
   * Counting, multiples of 5
   * Sum of numbers 1–100

4. **JS Functions**

   * Working age check
   * Multiplicity check
   * Triangle validity
   * Triangle & rectangle area calculation

5. **JS Objects**

   * Create objects, access & update properties
   * Object methods
   * Looping over object keys
   * Constructor functions
   * Object copying

6. **JS Arrays**

   * Create, copy, modify arrays
   * Iterate with `for`, `forEach`, `map`, `filter`
   * Calculate sums, averages, products
   * Work with objects in arrays
   * Find, remove, check elements (`some`, `every`, `findIndex`)

7. **JS Users Array**

   * Create `User` objects
   * Add prototype methods
   * Filter by subscription, gender, age
   * Find, update, remove users
   * Sort by age
   * Check emails
   * Validate if all subscribed

8. **JS Error**

   * Validate input in functions (`pow`, `email`)
   * Throw `TypeError` / `RangeError`
   * Catch errors with `try..catch`
   * Notify user of error type

9. **JS Closures**

   * Create counters with closures
   * Support custom step or initial value
   * Increment persists across calls

10. **JS Classes**

    * `Post` class with `id`, `title`, `author`, `text`, `date`, `likes`, `image`, `hashtags`
    * Methods: update text, change likes, add hashtags (with validation), render HTML
    * Demonstrate usage with multiple posts

11. **JS Map**

    * Create `Map` from array of pairs
    * Get size, add/delete elements
    * Check keys/values, retrieve values
    * Function to replace numbers in text with ordinal words

12. **JS Inheritance**

    * `Vehicle` class: `dimensions`, `brand`, `model`, `manufactureDate`, `getFullInfo()`, `getAge()`
    * `PassengerTransport`: adds `passengerLimit/count`, `addPassenger()`, overrides `getFullInfo()`
    * `FreightTransport`: adds `capacity/weight`, `checkLoadingPossibility()`, overrides `getFullInfo()`
    * Create instances and test functionality
